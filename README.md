# Career Opportunity Tracker

A free tracker that runs in Claude. It finds jobs that match your resume and companies that need your consulting or fractional services, drafts your applications and outreach, updates itself from your email, and keeps your weekly unemployment work search log ready.

Get it, with the install guide, at https://www.doovli.app

This folder holds the latest tracker files. Installed trackers read it to check for and install updates.
